# 1.金刚经

白居易真迹金刚经藏于苏州寺庙中，饥年被僧人拿去当了粮，被无偿返回。途中遇风，一页散佚。后常州太守为求经文，将住持关押，却因经文不全放了住持。住持与僧人返回途中于一老者家中找到散佚的经文

# 2.下棋

宋有个下棋厉害，自称小道人，打遍宋朝无敌手。后至辽国，看上辽国国手妙观。两者对弈，第一次妙观暗许以身相许后赖账，第二次于王公府中输棋又赖账，小道人告官方许

# 3.钿盒

翰林偶得钿盒半边，缘是儿女亲家的凭证，只不过男方已亡故。后翰林得遇美女，正是姻亲的女方，便冒认为男方与之结亲，之后方说明真相

# 4.财杀

张贡生想独占兄弟财产，故买通官府杨佥事，谁知佥事被罢了官。后张贡生赴京途中去佥事家要钱被杀。贡生两子一年后得知实情告了关，公差探得实情，佥事被抓

# 5.人贩子

大臣之子南陔元宵被拐，在途中呼救被宫人救，且在贼人衣服上留下记号，致使其团伙被一锅端。之前有王爷之女真珠族姬被拐，遭奸污，又被卖为妾，后方获救，也是这伙人所为

# 6.连理枝

翠翠与金定初是同窗，结为连理。翠翠为军人所掳，金定寻至，谎称兄妹，后两人具殁，同葬一处

# 7.淫妇

两代为官的董家后续弦了一个荡妇，致使董元广早逝。荡妇又勾结其同侪吕使君，致吕使君贬官身死，荡妇卖了董家孤女。后董前妻祝家后辈亦为官，偶遇董家孤女，已沦落风尘，与太守一起为之赎身，并将其嫁给昔日情郎

# 8.赌博

沈将仕受两人撺掇去王朝议家，见其妾赌博也加入进去，输了不少，后才知并非王朝议家，乃众人做局

# 9.幽会❤️

才子佳人约炮之时被朋友打搅未成，各奔东西，后互相许了人家，没想到许的正是彼此

# 10.私生子

莫老爷与婢女私通致其怀孕，把她许配人家。莫老爷归天，有五个泼皮撺掇他们去争家产告官，并骗他们画押。谁知莫家大公子直接认了小私生子，泼皮们告官不成，被官府发配了

# 11.负心汉

满生未第时困窘，受焦老救助，后安置己家，未想满生于女儿文姬私通，遂赘满生。后满生及第，薄幸另娶，被文姬与婢女之魂魄索命

# 12.朱熹傻逼

朱熹因唐仲友讽他，刑讯逼供官妓严蕊，结果严蕊坚贞不屈，得佳名

# 13.见鬼

野鬼借尸还魂，与友人诉妻子改嫁带走钱财，儿子沦为乞丐之事，友人告官，儿子获救

# 14.仙人跳

小宣教看中邻家妇，久勾不得，后及得见，夫归，讹多钱财，宣教后方知乃扎火囤，郁郁而终

# 15.行善

江老爹受人诬陷，顾相公力保，江老感恩，让女儿与之作妾，不受。又与徽商做义女，后嫁得侍郎。后偶遇顾相公，举荐得升

# 16.阴间报应

陈家为不与兄弟分田，假典于毛家，后来赎，毛家拿钱不认。报官未果，祭奠神鬼，阴间公道，毛氏身死，陈家也萧条日甚

# 17.女扮男装❤️

闻家有女女扮男装，与杜、魏二人同窗，闻射箭，谁先得嫁谁，杜先得箭，后到魏手，闻不知，以为魏先得。后闻父受陷入狱，闻女扮男装入京告冤，途中为景氏女看中，闻留魏之信物于景。后闻于京许杜，也说和魏与景，父冤得雪，两家亦成眷属

# 18.修仙🤎

甄监生好修仙炼丹，得方士丹药，与家婢春花房中行事暴毙。方士受监后得雪，春花改嫁后羞愤自缢

# 19.做梦🤎

有小孩无父无母称寄儿，于老翁家当牧童。梦中自为寄华，平步青云，娶了公主，立了军工。但梦中荣华现实就惨淡，后又梦中惨淡，结果现实中发现宝藏，被老翁收做养子。后病中遇梦中道人，随道人出家

# 20.骗钱

贾廉访贪财，儿媳妇家的钱都骗来了，结果死了阴间受罚

# 21.屈打成招

王爵来收兄弟王禄尸身钱财，分为两处，一处被车夫盗，一处不知何处，而自己与尼姑偷欢被和尚杀人劫财。一开始店家被屈打成招，索性青天大老爷出场，抓了和尚，抓了盗贼，所匿钱财原在棺中

# 22.败家

呆公子不知创业艰辛，与一帮狐朋狗友玩乐，钱都被挥霍。没钱了人就不理他了，穷困潦倒后知道守财了。幸得岳父提点，给了他点田产家业

# 23.小姨子

姐姐兴娘与崔生定下娃娃亲，后思虑崔生，郁郁而终。崔生来，小姨子庆娘夜诱之，第二天两人私奔一年。归家，方知是兴娘之魂思崔生，借庆娘身体相处一年

# 24.前世报应

元自实借了钱给缪家，不要借据，后元家遭难，去投缪家，且不认账，自实投井不死，乃知此是前世报应，今方得解，遵仙人言，去了别处，生活饮食，而缪家却遭身死

# 25.劫色

新娘子出嫁当日被歹人劫了出去，快被抓时扔到井中，后被两人遇到，一人下去救时被另一人砸死，新娘子又被劫走，后报官方得回家

# 26.穷教官

高老教官止仨女一侄，初有钱时各住女儿家，钱没了被嫌弃，流落侄儿家。后学生高升，多有所报，给老教官的钱也留给了侄儿

# 27.绑票

汪生与妾回风同游，回风为强人所抢，汪生借军船装作官家接回回风

# 28.无头案

程朝奉看上卖酒妻，用钱约上，待去赴约却见一无头女尸，原是淫僧砍了。寻头时又寻到一个男人头，缘是过去一桩命案，一道把凶手抓了

# 29.狐仙

蒋生是个买卖人，看上了马家小姐，谁知马家小姐夜夜来会，后以芝麻访得其踪迹，乃是狐仙。狐赠其三草，一强体，二使马小姐生癞，三救马小姐，蒋生得入赘马家

# 30.幽婚

韩秀才路埋一骸，骸之魂魄来寻，方知是宋时义女王玉英，玉英感恩，与之结为幽婚，育有一子，送人抚养，后子大高中，玉英魂归

# 31.检尸

王生之父被打死，为了不验尸破坏尸身，假意宽恕，至得子后杀了仇人，报官后只要验尸就可不死，为不验父尸，自杀身亡，其妻等三年孩子断奶后殉夫

# 32.天锡

朱家子先纳妾后娶妻，娶妻时就把妾遣了，后来小朱挂了，妾生子未嫁，老朱以为绝后，后得知其妾有子，接回来取名天锡，谁知道妾也给他取名天锡

# 33.怪力乱神

杨抽马善怪力乱神，找人打自己与老婆别人不肯，后来果然被收监打了20下。又向人借钱，别人不肯就招一个妇人魂魄晚上吓他，然后才肯借钱

# 34.内闱🤎

太尉外出，任生进去与诸妾厮混，太尉得知，阉了他

# 35.误会烈女🤎

孙小官以为闰娘约她，没想到抱了她妈方氏，她妈一骂闰年就上吊了。方氏以为闰娘死了，把孙小官骗来关了，然后去告官，孙小官准备奸尸，闰年却活了，遂结婚

# 36.宝镜

渔翁王甲与妻平日行善，得宝镜，至富贵。献于寺庙，不想被僧人用赝品换了。僧人富足，官府眼红，抓了僧人，不交，死于狱中，寺庙行者偷出钱财与宝镜，被神仙弄死，宝镜拿回，钱给了王甲

# 37.海神

徽商程宰经商不善，后海神夜夜来会，助其发财消灾

# 38.私奔

人妻莫大家约着与杨二郎私奔，却被别人得知，醉后被骗走，后被卖与娼家。杨二郎获诬入狱，后莫大姐被解救出，嫁与杨二郎

# 39.侠盗

苏州侠盗懒龙（一枝梅）诸事

# 菊花的幽香

矿工妻子久待丈夫不归，以为他又去喝酒去了。后来却传来了他遇难的消息，但妻子却比较淡漠。

# **普鲁士军官**

上尉虐待勤务兵，后被勤务兵刀了，勤务兵也在途中死去。

讲述了普鲁士军官与其勤务兵之间因战争的残酷和军队内的压抑而产生的互相憎恶又互相吸引的复杂情感。

# 英格兰，我的英格兰

丈夫在家庭中毫不履行做丈夫和父亲的责任，不工作不挣钱，生活费用绝大部分由老丈人承担。妻子希望他有些恶劣癖好，或者透出点小流氓举止，也好为他的不负责任找点指责他的借口，可他就是举止优雅，具有英国绅士应有的一切礼仪风范。

后来孩子们的出生，特别是大女儿的受伤，加快了两人的疏离。最后丈夫死在了战场。

# 马贩子的女儿

故事以梅布尔一家早饭后的谈话为开端。梅布尔出身于一个马贩子家庭，家境曾一度富足，但父亲去世后家道中落。在得知必须离开家园另谋生路后，梅布尔的三个哥哥冷酷无能，决定要赶走梅布尔以减轻负担。

在为母亲上完坟后，梅布尔选择了溺水来结束自己无望的生命，但被年轻的乡村医生费格森从水中救出。这一意外的获救经历让梅布尔重新燃起了生命之火，而费格森也被她的美丽和坚韧所吸引，两人之间逐渐产生了微妙的爱情。

# 你触摸了我

玛蒂尔德把父亲的养子哈德良错当成父亲，从而触摸了他。哈德良为此想得到她，而父亲也决定修改遗嘱，若她不嫁给他就得不到财产。最后玛蒂尔德嫁给了哈德良。

# 公主

多莉在父亲的教导下，严守沉默，不与除父亲外的任何人亲昵。在父亲去世后，多莉开始与异性交往。在新墨西哥州，她遇见了印第安向导多明哥·罗梅罗，并被他的外貌和气质所吸引。在离开之前，她要求罗梅罗带她去深山小屋看大一点的野兽出没。

在深山小屋中，夜晚的寒冷促使多莉要求罗梅罗为其取暖，两人很自然地发生了关系。但第二天，多莉否认了她对罗梅罗的感受，这让罗梅罗倍感欺辱。为了把她留在身边，罗梅罗软禁了她。

罗梅罗与来寻找多莉的警察发生了枪战，最终被打死了。多莉在回到往日生活后，嫁给了一位上了年纪的男人，并且过得相当快活。

# 两只蓝鸟

吉先生和吉太太是一对深爱彼此的夫妻，但他们的婚姻生活却并不幸福。吉先生每天忙于写作，为了排遣寂寞，吉太太选择去南方度假，并在那里与情人调情。与此同时，吉先生的女秘书则把家里打理得井井有条。

吉先生对妻子的出轨行为似乎并不在意，他依靠女秘书来打理生活和工作，一方面是因为自己失去了“血性意识”，习惯了养尊处优的生活；另一方面，这也是他对抗风流妻子的一种手段。然而，这种关系却给所有人都带来了痛苦和困惑。

# 骑马出走的女人

白人女性深感西方文明的虚伪，渴望寻找一种更加纯粹和原始的精神力量。深思熟虑后，她决定骑马出走，去寻找她心中的理想世界。

在旅程中，她遇到了印第安人。她被他们的原始宗教和神秘文化所吸引，决定投奔印第安人，并甘愿献身于印第安神明。

# 太阳

朱丽叶长期生活在城市中，与自然的亲近机会非常少，这导致她产生烦躁心理。医生建议她采用西西里岛的日光浴治疗。朱丽叶接受了医生的建议，带着儿子一同前往。

最终，朱丽叶在自然的抚慰下实现了精神的重生。她意识到自己是自然的产物，生活必须依赖自然、融入自然。同时，她也明白了人与自然是不可分割的，自然不仅能够为人类提供外在的资源，还能够净化人的心灵、洗涤人的灵魂。

# 美妇人

波琳通过自己的美貌，潜意识里控制着两个儿子，已故的亨利和罗伯特。罗伯特在母亲的控制下，变得平庸无能，缺乏自信。

西西莉亚寄居在波琳家中，她注意到了波琳对罗伯特的控制，她一方面向罗伯特表白自己的心意；另一方面假冒死去的亨利向波琳发出警告。

西西莉亚的抗争对波琳产生了巨大的打击。她失去了对罗伯特的控制，精神崩溃，旋即死去。而罗伯特则在西西莉亚的帮助下重新找回了自我。

# 牧师的女儿们

随着煤矿的开采，新居民涌入村庄，带来了不同的生活方式和观念。牧师的女儿们开始接触到这些新变化，她们的心灵也受到了冲击和影响。

高瘦的姐姐嫁给了瘦小的马西，矮胖的路易莎嫁给了矿工杜伦特。

作品中深入描绘了牧师女儿们性的觉醒和萌动，她们在性的探索中寻求自我和情感的满足。这种描写既具有人性味，又充满了肉感的温情。

# 狐

班德福与玛奇一起经营农庄，一天，一只神秘的狐狸出现在农场，激发了玛奇内心深处的情感波澜。狐狸在玛奇眼里具有了男性的吸引力。

随着狐狸的频繁出现，玛奇逐渐意识到自己对男性的需求和向往。玛奇在追求自由与爱情的过程中，面临着来自班福德的阻碍。班福德的固执和占有欲让玛奇感到困惑和疲惫。

最终，亨利蓄意地，然而却又是非常意外地“杀死”了班福德，使玛奇获得了自由。她摆脱了与班福德的纠缠，也摆脱了沉闷的农场生活，与亨利走到了一起。

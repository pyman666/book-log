# 说文解字

仓颉造字：有巫术的作用，战国末期才有，缘战国末期需要统一，故一个圣人造字是有需要的；

秦：始皇以前称“大篆”，或“籀zhòu文”。始皇后称“小篆”；

说文解字：周宣王的太史籀作《史籀篇》，相传是最早的字书。始皇名李斯赵高胡母敬作了七章字书。东汉许慎作《说文解字》，是划时代的字书，收小篆、籀文及其它别体字；

小学：研究文字的形音义的叫“小学”，现称文字学。《说文解字》是小学古典，又是一切古典的工具或门径；

铭文：古器物可的文字叫铭文，铜器的铭文称金文，宋代出土发现了很多金文，多是周代所作。清代发现甲骨文，是商代文字；

造字和用字的条例：略；

书体：书体从小篆、隶书、汉隶、章草、今草、楷书、行书、简笔字的演变，多是求应用便利的缘故；

# 周易

讲五行的，现有《尚书 洪范》，讲八卦的是《周易》；

卜法用骨，后有筮shì法用草，八卦大概是有了筮法之后才有的。后来发展出了64卦，就是《周易》里的卦数。筮法判定吉凶的辞叫繇zhòu辞，周易里一卦六画，每画叫一爻yáo。西周初叶的卜筮官将卦爻辞按卦爻顺序编辑起来就是《周易》，“易”就是“简易”的意思，《周易》原来只是一部切用的筮书；

战国末期儒家受阴阳家和道家影响，给《周易》的卦爻辞作了新解释以发挥其哲学，这些新解释存下来就是《易传》。《文言》解释乾坤两卦，《系辞》发挥宇宙人生观，是最重要的一部《易传》；

儒家的《周易》是哲学化了的，民众的《周易》倒是巫术的本来面目；

# 尚书

《尚书》是中国最古的记言的历史，包括虞夏商周四代，大部分是号令，小部分是君臣相告的话；

汉文帝命人从伏生处学习的用隶书钞录的称为《今文尚书》，汉景帝时从孔子旧宅墙壁得到的用“古文”（晚周民间别体字）写的称为《古文尚书》，比今文多16篇，今古文之争是西汉经学一大史迹。

汉末《古文尚书》失传，三国魏国王肃伪作了《孔子家语》《孔从子》等，蒙混千年，直至清代经阎若璩qú、惠栋、丁晏等大师的工作，方有定论；

# 诗经

诗的源头是歌谣。歌谣可分为徒歌和乐歌，即随口唱和随乐器唱。乐工的唱本保存下来就是《诗经》。古有借用诗篇作政治暗示等传统，称为“诗言志”，孔子发扬之，用诗进行教化。随着借用渐多，诗义不显，诸多儒生随孔子断章取义解释《诗经》，最权威的是毛氏《诗传》。大毛公毛亨创始《诗经》注解，小毛公毛苌cháng完成之。“以史证诗”的思想最先具体体现在《诗序》，诗序有大序和小序。郑玄《诗笺》集以史证诗之大成；

“六义”风雅颂赋比兴：略；

# 三礼

天地君亲师，天地、祖先、君师，荀子称其为礼的“三本”。儒家拿礼来包罗万象，认礼为治乱的根本，这种思想可以叫做“礼治主义”。从来礼乐并称，乐是礼的一部分。汉学者传习的有三种经和无数“记”，三经《礼古经》《仪礼》《周礼》，“记”是儒家礼论之作，又叫《礼记》，流传至今有38《大戴记》49《小戴记》，大小戴即戴德戴圣，后世所称《礼记》多指《小戴记》。

# 春秋三传

“春秋”诗古代记事史书的通称。各国都有《春秋》，但传下来的只有《鲁春秋》，《春秋》是我国现存的第一部编年史。《春秋》三传：《左传》《公羊传》《谷梁传》，三传尤其是后两者，和《毛诗》传、笺，在穿凿解经这件事上是一致的。三传之中，公羊、谷梁两家全以解经为主，左传以叙事为主。另有一部分国记载的《国语》，重在“语”，记事颇简略，近人认为是《左传》的重要史料之一。

# 四书

五经《诗》《书》《礼》《易》《春秋》，四书《大学》《中庸》《论语》《孟子》。《大学》《中庸》都在《礼记》里。从前私塾里，学生入学，都是从“四书”读起的；

朱熹诸多作用：略；

# 战国策

战国时代，封建制度逐渐崩坏，养士之风兴起。外交办得好，只凭口舌排难解纷，也可多找一些帮手，担负外交的人便是策士，即游说之士。合纵派代表苏秦，连横派代表张仪。《战国策》是记载那些说辞的书，汉代刘向编定，战国的名称也是刘向在这部书的序里定出的。

# 史记汉书

《史记》创了“纪传体”，共一百三十篇，列传过半，司马迁的史观是以人物为中心的。《史记》之后续作很多，班彪加以整理补充，著65篇《后传》，其子班固用其作《汉书》底本。后因窦宪之祸死于狱中，其妹班昭（曹大家）和马续奉诏整理完善《汉书》。

《史记》感慨多，微情妙旨，时在文字蹊径之外；《汉书》一览之余，情词俱尽。二书并称良史。

# 诸子

春秋末年，封建崩坏，贵族失势，农奴解放，商人抬头，政治经济起了根本变化，形成了一个大解放的平等自由的时代。

诸子都出于职业的“士”，士本是封建制度贵族的末一级，但到了春秋战国时期，已成为有才能的人都通称。

儒：孔子，孟子，荀子。儒士多半是上层社会的失业流民，其所拥护的制度，也是上层社会所讲所行的；

墨：墨子。有组织，有主义，反对侵略，是平民的代言人；

道：杨朱，老子，庄子。道家出于隐士，反对一切文化和制度；

名：惠施，公孙龙。辩者，出于讼师；

法：韩非子。法家出于”法术之士“，即以政治为职业的专家；

阴阳：驺衍。创“五德终始”说；

吕不韦《吕氏春秋》刘安《淮南子》都以道家为基调尝试统一思想，后董仲舒说服汉武帝独尊儒术。

# 辞赋

辞：屈原受庄学影响极大，也受阴阳家影响，沾了“齐气”；“兮”字足句，句读参差，大概有音乐的影响。模仿者宋玉最出色。汉代仿屈原宋玉者众，汉人称这种体制为“辞”，刘向将这些编辑成《楚辞》一书；

赋：荀子最早称赋，贾谊将屈辞荀赋两体合一。汉分赋为四类：1、杂赋，是总集。2、屈原，言情。3、陆贾，纵横家言。4、荀卿，叙物明理。司马相如以来，有散文化趋势，班固张衡左思以来，散文化更进一步。后专重写景述情，不用来讽谏，南朝唐初极盛。古文运动至宋，欧阳修苏轼，“文体”的赋。赋是我国的特有体制，与文更近些，不算是诗；

# 诗

汉：乐府，即乐歌，异于雅乐（诗经），两种新调子：楚声，新声，五言诗的源头。汉文人仿乐府作五言，期间成就最高的是《古诗十九首》；

魏晋：三曹发展五言。阮籍第一个全力作五言，扩大了诗的范围，成立了抒情无言。陶渊明谢灵运在诗中发现了“我”，陶赏味田园，写意，谢赏味山水，工笔；

南北朝：“声律说”大盛，重句中的“和”。宫体诗盛，七言诗发展；

唐：谐调发展，成立了律诗绝句，称为近体，不是谐调的称为古体。李白给新体立下了标准，杜甫继往开来，抒写那个时代，扩大了诗的领域和价值，古体七言到他手里正式成立，古体五言到他手里变了格调；韩愈元稹白居易继续发展，晚唐李商隐杜牧继续发展；

两宋：宋初学李商隐，欧阳修梅尧臣发现了汉语，起始了宋诗的散文化，苏轼而极。黄庭坚第一个有意地讲究诗的技巧，学杜甫，开了江西诗派。南宋三大诗家杨万里范成大陆游都是从江西诗派变化出来的；

# 文

商代卜辞，《周易》卦爻，《鲁春秋》：“不成章节”；

尚书：”成了篇“；

讼辞，（外交）辞令：如子产，孔子很注意辞命；

诸子：议论文，辩，寓言，譬喻；

论语：第一种私家著作；

吕氏春秋：第一部有系统的书；

淮南子：才按照逻辑秩序，结构严密；

春秋左氏传：记事文里程碑；

史记：第一部有自己的系统的史书，文字最大的贡献，还在描写人物；

汉赋，骈文：汉代是赋的时代，骈文便这样开始发展；

文选：梁昭明太子第一次提出“文”的标准；

佛典翻译：增扩了国语的词汇/句式；

义疏，故，解，传，注，注疏：影响至清代的考证文；

古文：韩愈，柳宗元，欧阳修，曾巩，王安石，三苏；

语录：唐，起于禅宗；

传奇：唐，记述艳情神怪；

话本：宋，白话小说的老祖宗；

章回小说：元《三国志演义》还夹杂着“雅言”，《水浒传》《西游记》便都是白话了。这些故事关联，却不是联贯的。直至《红楼梦》，近于“长篇小说”；

八股文：明代用八股文取士；

桐城派：方苞，姚鼐，曾国藩；

新文体：梁启超；

白话文：胡适之，五四运动；

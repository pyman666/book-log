# 叶尔莫莱和磨坊主妇

我带着雇佣的猎人叶尔莫莱，日落前在树林里“守猎”。为了第二天日出前“守猎”，他们想在附近一个磨房里过夜。磨房主怕引起火灾，所以拒绝了他们的请求，但最后还是安排他们住在不远处一个小棚里。后来，磨房主叫他妻子阿丽娜出来招待这两位不速之客。原来阿丽娜是一个地主太太的贴身丫头，由于要求与地主老爷的贴身男仆结婚而被撵到乡下。是她现在的丈夫花钱为她赎的身。看来叶尔莫莱与她有旧情。

# 莓泉

我带着猎犬出去打猎，由于炎热难熬，所以来到附近闻名的“莓泉”，见到了两个农民：一个叫斯交布希卡，流落在外无家可归，现在寄住在给主人管菜园的米特罗方的菜园；另一个绰号叫“雾”，曾是已故伯爵的管家，他现在七十左右，如今寄住在县城一个旅店老板那里。从他口里得知，伯爵生前风光了一阵子，后来倾家荡产，死于旅馆的客房里。老人对自己的主人至今有好感，怀念多于埋怨。

# 我的邻居拉其洛夫

小地主拉其洛夫也是一个正在变穷的小地主。他至多五十来岁，曾在陆军步兵团服役了十来年，当过兵，打过仗，参加过俄、土战争，而且负过伤，住过院，几乎送了命。他见多识广，谈吐自由，但性情内向。他结过婚，但三年后妻子因难产病故。现在他和妻子的妹妹奥丽佳双方有意，最后他带着姑娘离家出走，抛下了他的母亲和家。这事件在省里引起了轰动。

# 独院地主奥夫谢尼科夫

从富农奥夫谢尼科夫口里，读者知道一批地主贵族，大的和小的，好的坏的，老式的和新式的，开明的和吝啬的，俄国土生土长的，外国后来的，各种类型都有，其中包括我的外公外婆。此外，小说还写到奥夫谢尼科夫的亲侄子米嘉，叔侄二人都是小说从正面肯定的主要人物。特别是富农奥夫谢尼科夫，简直就是我心目中的英雄。

# 李郭堡

我和猎人叶尔莫莱到距离李郭堡十里的芦苇荡里撑船打野鸭遇到危险。中间，先遇到华而不实的猎人符拉基米尔，“他是地主家一个解除了奴隶身分的仆人”；然后又找到看管一个破木船的渔夫、绰号“干树枝”的老人苏跷克，他先后为地主贵族老爷当过仆从、厨子、车夫，现在是渔夫。我们四人就是坐着他那只破旧不堪的平底木板船在芦苇荡打猎的。

# 白净草原 ★

我因为贪恋打猎晚归，回家途中迷了路，后来只好跟五个小孩儿在河湾大草地的篝火旁边过夜，我假装睡着了，听到了孩子们的谈话：主要是关于家神、美人鱼的迷信和神话，以及当地发生过的一些传说。

# 美人梅奇河的卡西央 ★

我打猎归来，坐在马车上，在路上碰到出殡的队伍，为了避开这“不祥之兆”，车夫赶马向前，结果车轴坏了。为了买新的车轴，我们来到了只有六户穷苦农民的“移民新村”，我见到了侏儒卡西央，由他陪同到了伐木场买车轴和打鸟，从我和他的交谈中了解到卡西央的身世和为人。在伐木场度过了后半天，返回新村前见到了的小姑娘小安娜——可能就是老人的私生女。

# 总管

这不是一般的地主家里的管家，他的儿子当村长，他自己被主人委派掌管庄园， “天高皇帝远”，他成了田庄真正的“主人”或老爷，在庄园当家做主、发号施令。此人聪明能干，地主老爷喜欢他和赏识他，但当地农民怕他、恨他，骂他是吃人的恶狗。

# 事务所

我打猎归来，为了找一个避雨的地方，经一个看守窝棚的老人指点，来到女主人的田庄管理处，被管理处的主要负责人安排在隔壁的房间里睡觉、休息。我透过间壁的空隙看见和听见管理处发生的一切，特别是主要负责人的所说、所为。管理处虽然由六人组成，小伙子说这里没有总管，但尼古拉·叶列美奇就是总管。他在一天里接待的三个人：买秧苗的商人、林场来求他的木工西道尔、找他吵架的医生保罗，从中可见他的忙碌和精明，也可见他的卑鄙和险恶。

# 孤狼

傍晚我打猎归来，天气突变，拉车的母马陷在泥泞中拔不出腿。此时看林人帮我走出困境，并带到他家。雨过天清后，看林人准备送我回家，但此时听见有人偷砍树木，于是到树林一举擒获了那个农民，带回家中。经我的帮助，他最终放了那个农民。

# 两个地主

两个性格各异的地主：一个是个退伍军官，瞧不起无钱无势的贵族。他还没有娶妻，很好色。他喜欢打牌，但只愿同身份低的人打，这样他可以随便喝斥。他很吝啬，所以竟不愿意接受贵族长这样的荣誉头衔，大概怕开销大，不合算；另一个自称是“老实人”，照章办事，生活中的一切都保持古风。

# 列别强集市

描绘了集市的热闹场面和当地居民的生活，展现了外省小城的社会风貌。

# 塔佳娜·鲍利索夫娜的侄子

穷地主塔佳娜·鲍利索夫娜五十来岁，很早就守寡，她收养并培养了侄儿，但侄儿学画没有成功，白花了她的钱和心血。

# 死亡 ★

作者先后写了五个俄罗斯人的死：第一个是伐木场上被伐倒的大树压伤致死的包工头；第二个是在地主家干活儿的一个农民，他“在谷物干燥房被大火烧得半死”，被人拉出了来后不久就死在自己的炕上；第三个是一个患疝气的磨房主，这病本来好治，但他耽误了治疗，而且一误再误，不治而死；第四个是我大学时的同学，他大学未毕业无家可归，为生活所迫，带着肺病在地主家当家庭教师，不久就死在他家里，；第五个是一个地主老太婆，她是病死的，死得也很平静，临死前还从“枕头底下拿一个卢布想支付牧师的祷告费”。

# 歌手 ★

离峡谷源头不远处有一个小酒店，我路经此地，进酒店歇脚避暑，正当两个歌手在三个听众兼裁判的鼓动下准备赛歌。赛歌结束后我离开了酒店。

# 幽会 ★

我在林中目睹了一对青年情侣离别前最后一次幽会的情景，男方的感情不深，在离别前表现冷漠，而女方的感情真挚热烈。

# 希格雷县的哈姆莱特 ★

我在邻村一个小地主的宴会之后，认识了同房的“哈姆雷特”：他出生于一个地主贵族家庭，他是母亲一手培养长大，母亲专门为他请了一个德国人当法语家庭教师。他刚满十六岁，母亲送他到莫斯科进了大学。不久母亲去世。他的家产委托他叔叔代管，只留了小部分给他，但他几乎全部卖掉，在外国留学时花掉了。在国外还与一个德国教授的女儿恋爱，后来回到莫斯科，但因为受不了谣言中伤，不久就回到自己的村庄，又很快跟邻村一个女地主的女儿正式结婚。婚后他发现妻子受过心灵创伤，后来他妻子因难产死去。过着单身汉生活的他穷困潦倒之余只得常去邻村地主家串门混吃。

# 且尔托泼哈诺夫和聂道比斯金

我和叶尔莫莱打猎回来，在路上先后遇到了且尔托泼哈诺夫和聂道比斯金，这是两个小地主。前者祖辈是“侍侯过沙皇”的世袭贵族，但由于父亲治理无方，导致破产，临死只遗留下一个小村子给他；后者之前是地主的侍从，地主临死前决定奖赏他一个村子，并且写进了遗嘱。一个当官的继承人企图否认遗嘱的这部分内容，当众奚落后者，前者挺身而出，使后者获得了这笔遗产，他们俩成了莫逆之交。

# 活尸首 ★

露克丽亚原是我家一个最漂亮的女仆，但在一次意外之后只能卧病在床，成为别人口中的“活尸首”，但是她虔诚的信仰却深深感染着我。

# 车轮子响

因为马受伤，所以我借由乡下人非落非驾马一起前往目的地， 因为不停非落非的劝告，从而半路遇匪，但最终化险为夷。

# 森林与草原 ★

全篇写的是猎人喜欢的树林和草原在春夏秋冬四季的自然风光。

# 霍尔和卡里瑞奇

我以在旷野里结识了小地主波鲁徳金，他邀请我到他那里过夜，因为路远，先步行到了“黄鼠狼”霍尔的家，但霍尔进城去了。于是由他小儿子瓦西亚驾车送我们回波鲁徳金家过夜。第二天我一个人出外打猎，返回途中顺便来到霍尔的家，与他多次长谈，了解了许多情况。恰好有一次卡里瑞奇也来看朋友霍尔。第四天傍晚，波鲁徳金派卡里瑞奇来接我，于是我跟霍尔告别。

# 1.荡女互助

花二姐与任三偷情，任三未婚妻有孕花二姐助其偷偷流产，李二发觉花二姐偷情约花二捉奸，被未婚妻母知，告知后捉奸不成，李二被反杀

# 2.转世报仇

吴胜战场拿了牺牲战友的钱回乡，借宿陈栋家，小二撺掇陈栋害了吴胜。后陈栋路遇一小孩，收养之，取名陈三元，乃吴胜投胎。后陈栋误死，小二被抓，死于狱中。三元娶了吴胜未婚妻，三元弟弟娶了小二老婆

# 3.弑兄盗嫂 💛

章必英盗嫂李月仙，推兄王文甫入水不死，必英入监，后遇赦。必英卖沟李禁，诬兄兄入狱，逼嫂下嫁，后对嫂吐真言，月仙出门告官，文甫得赦，必英被捉

# 4.男扮女装

香菜根丘继修男扮女装与张英妻行奸，后张英归，杀妻、侍女爱莲，诬丘。后爱莲还魂告冤，罢张英官职

# 5.强抢人妻

蒋青看中刘玉老婆，与下人三才偷到自己家里，后蒋青上了三才老婆文欢，被三才反杀，三才自尽，家财老婆又归了刘玉

# 6.纯爱被杀

王卞伴读柏青吹箫见到花仙，误以为她家小姐有意，去了她家被杀，王卞被误认为凶手被抓，花仙自首，后王卞科举得中，去了小姐和花仙

# 7.邻人之妻

陈彩看中邻家贫人之妻犹氏，杀之夺妻。后与犹氏装逼时吐露谋杀真相，犹氏告官

# 8.淫杀人妻

念三与福来交好，与其妻通奸，其妻想杀了福来与念三交好，被念三反杀。后其妻显灵，念三被捕

# 9.合伙开店

小山让老婆色诱二官合伙开店，老婆给二官生了儿子，小山后来气死了，二官娶了他老婆

# 10.约炮被抓

许玄与邻家施小姐双双做梦啪啪，遂偷偷约炮，有一次约炮被人看见收监，后逃出去考试，又有阮小姐说亡夫托梦，遂啪啪。后科举得中，娶施、仆秋鸿、阮

# 11.路遇淫僧

路上遇到几个淫僧被囚，成为性奴，后逃出告官

# 12.贪财被骗

汪云生是个吝啬鬼，一日下雨，王氏两人躲雨，说妹夫家有钱，但人死光了，汪见财起意，娶了王氏，没多久两人就卷着钱跑了

# 13.换妻游戏

b看上了a的男宠张扬，a看上了b的养的妓玉香，张扬就让b来找他，a乘机去偷玉香，后b又看上了a的妾巧儿，张扬又让a找玉香时b去盗巧儿。后事发，被县太爷打了

# 14.淫僧情杀

淫僧了然因妓女要去陪另一个客人杀之，后她人扮作其鬼魂吓唬了然，案情得雪

# 15.打水奇缘

宋仁帮王文老婆玉贞打了几次水，两人跑了，玉贞在西湖边成了暗娼。后寻回，宋仁被监，玉贞与王文和好如初

# 16.躲难遇难

夫妻俩算命躲难到外租一户，房东看上他老婆污他下狱，房东老婆偷偷让他老婆溜了，他在狱中被人偷偷放了，后来高中，房东被一侠盗杀了

# 17.重金求子

教书先生看上了某妾，另一个妾遂借其名与教书先生私通求子，后生完孩子死了，教书先生也死了

# 18.休妻又娶

一妇回家遇雨，在亭中避雨，有一柳下惠也来避雨，后妇夫得知，休了她。后与柳下惠同科及第，知了真相，又娶了回来

# 19.友人之妻

木知日把老婆孩子还有家业托付朋友江仁，不想江仁淫妻丁氏，敛财自家，仆人去告诉不信，仆人自杀，其鬼魂让江仁和丁氏死了，木知日还娶了江仁老婆

# 20.偷香窃财

强盗扮作秀才住在寡妇房东家，暗合。一日将所有人灌醉，把东西都偷走了

# 21.约炮被杀

小朱仗着有钱，到处偷人老婆，一次约炮后被人涂成鬼，走到自家门口被人当鬼打死了

# 22.偷欢尼姑

小黄跟尼姑啪啪啪被抓，后放回

# 23.遇仙人跳

小王去考试，路遇姐弟，都上了，结果钱都被偷了

# 24.侠盗二事

侠盗一枝梅二事

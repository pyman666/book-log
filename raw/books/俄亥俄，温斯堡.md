[小城畸人](https://baike.baidu.com/item/小城畸人/3242750?fromtitle=小镇畸人&fromid=7711409)

[俄亥俄,温斯堡 - 搜狗百科](https://baike.sogou.com/v76665167.htm)

表面上是21个小镇怪人的独立故事，实际上很多人物互相串联，而乔治·威拉德是连接全书的核心人物。

可以简单看成：

**少年乔治 → 接触一个个“畸人” → 经历性、爱情、孤独和死亡 → 逐渐理解成年人 → 最后离开小镇。**


| 篇目                         | 剧情简介                                                                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **畸人志**                    | 一个老作家听木匠讲起各种怪人和怪事，由此想到：每个人都可能因为抓住某个“真理”而变得古怪、孤独。它相当于全书的总序。                                                                                   |
| **1. 手**                   | 小学教师比德尔鲍姆因喜欢抚摸学生的头发，被误认为对男孩有不轨行为，只得改名逃到温斯堡。他始终害怕自己的手暴露过去，但仍渴望与乔治·威拉德亲近。                                                                      |
| **2. 纸团**                  | 里菲医生把自己的思考写在小纸片上，揉成一个个纸团塞进口袋。一个富有姑娘因怀孕而找到他，两人因为彼此理解而结婚，但她第二年便去世了。                                                           |
| **3. 母亲**                  | 乔治的母亲伊丽莎白对失败的婚姻和丈夫汤姆充满怨恨，把希望寄托在儿子身上，甚至一度想杀掉丈夫。她最终没有这样做，只能继续把自己的未实现人生寄托给乔治。                                                                   |
| **4. 哲学家**                 | 帕雪瓦尔医生经常向乔治讲自己的“哲学”，宣称世人都是受难的“基督”。镇上一个孩子被马车撞死后，他害怕被人群报复，躲在办公室里，暴露出自己的恐惧和荒诞。                                                     |
| **5. 没有人知道**               | 路易丝·特鲁年主动给乔治写纸条约会，乔治与她发生性关系。两人都害怕别人知道这件事，故事因此围绕“没人知道”展开，表现乔治第一次真正跨入成人世界。                                                          |
| **6. 虔诚**       | 杰西·本特利是一个把宗教、土地和权力混在一起的农场主，一心想让自己成为上帝认可的“虔诚之人”；他的女儿路易丝却厌恶父亲的控制，后来嫁给银行家约翰·哈代并生下大卫。杰西最终把自己的宗教狂热强加给外孙大卫，要求他像《圣经》里的亚伯拉罕一样杀死自己，导致大卫恐惧逃走，整个家庭彻底崩裂。 |
| **7. 点子王**                 | 乔·韦林是个满脑子奇思妙想、说话停不下来的人，在小镇上显得滑稽可笑。但他突然认真追求莎拉·金，并通过自己的热情赢得她父亲和哥哥的认可，终于找到了归属感。                                                                 |
| **8. 历险记**                 | 爱丽丝·欣德曼年轻时被恋人内德抛弃，此后一直等他回来，十年过去仍没有结婚。她终于忍不住在雨夜脱光衣服跑到街上，却马上羞愧地逃回去，重新接受孤独的生活。                                                 |
| **9. 可敬与体面**               | 电报员沃什·威廉斯因为妻子背叛、岳母又帮着妻子而痛恨女人，变得肮脏、粗暴、厌恶一切亲密关系。他把自己的婚姻悲剧讲给乔治听，还试图让乔治也相信女人不值得信任。                                               |
| **10. 思想家**                | 塞思·里奇蒙觉得自己和小镇格格不入，又暗恋银行家的女儿海伦·怀特；但当他终于接近海伦时，她却劝他离开温斯堡。塞思最终决定离开小镇，认为自己大概永远无法真正融入别人。                                                           |
| **11. 坦迪**                 | 一个酗酒的陌生人来到汤姆·哈德家，自称一直在寻找一个叫“Tandy”的女人——在他心里，这个名字代表勇敢、真实、能够爱人的女性。临走前他把这个名字送给汤姆的小女儿，女孩从此要求大家叫自己坦迪。                           |
| **12. 上帝之力**               | 牧师柯蒂斯·哈特曼从教堂钟楼偷看女教师凯特·斯威夫特，被欲望折磨。一天他看见凯特裸体祈祷，以为这是上帝给自己的启示，于是砸碎窥视用的窗户，重新找回宗教信仰。                                               |
| **13. 女教师**                | 凯特·斯威夫特原本想把自己关于文学、人生的理解传给乔治，希望他成为真正的作家，但谈话逐渐变成男女之间的欲望。她突然亲近又突然逃走，乔治只留下困惑。                                                   |
| **14. 孤独**                 | 伊诺克·鲁滨逊离开温斯堡到纽约生活，把自己想象出来的朋友住进自己的公寓。后来他爱上一个现实中的女人，并向她介绍这些“朋友”，结果想象中的人物仿佛离开了他，他重新陷入彻底孤独。                                        |
| **15. 醒悟**                 | 乔治某夜散步时产生强烈的“男性力量”与人生顿悟，觉得自己终于成熟了，于是去找贝尔·卡彭特。但他试图证明自己的成熟时，被贝尔的情人、酒吧伙计埃德·汉比狠狠揍了一顿，所谓“觉醒”随即破灭。                                      |
| **16. “古怪”**               | 埃尔默·考利一家在镇上被认为是怪人，埃尔默因此怨恨整个温斯堡，尤其怨恨乔治。一次争执后，他把乔治打倒，然后跳上火车逃离小镇。                                                                 |
| **17. 未曾说出的谎言**            | 农场主雷·皮尔逊和同事哈尔在深夜干活时聊天，哈尔突然说自己想抛弃妻子和家庭。雷其实也曾产生过同样的念头，但最后选择回家，并没有把这个秘密告诉任何人。                                                                   |
| **18. 醉酒**                 | 汤姆·福斯特来到温斯堡后戒酒成功，找到工作并爱上一个女孩。他喝醉后幻想自己与女孩的关系已经实现，但清醒后发现那只是自己的幻想，于是故事呈现出他孤独而可怜的内心。                                                             |
| **19. 死亡**                 | 伊丽莎白年轻时曾在失意时与里菲医生产生感情，两人彼此理解，却没有真正结合。多年后伊丽莎白临终，里菲陪伴她，而乔治也在母亲死亡后真正意识到童年已经结束。                                               |
| **20. 成熟** | 乔治和海伦·怀特在乡镇集市后一起散步，两人都意识到自己正在长大，也都感到孤独。他们短暂地拥抱、亲吻，却没有发生关系，而是在彼此身上获得了一种成年人的理解。                                                                |
| **21. 离去**                 | 乔治终于决定离开温斯堡去大城市发展，父亲把他送上火车。火车启动后，他回望小镇，意识到自己已经不再是那个少年，正式结束了青春时代。                                                                             |

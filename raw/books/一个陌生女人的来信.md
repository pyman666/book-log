# 一个陌生女人的来信
作家R在生日收到一封临死女人的长信，得知一个女人从少女时代起爱了他一生，甚至为他生子，但他始终没有真正认出她；女人在孩子死后也走向死亡
# 灼人的秘密
度假的男爵想要引诱一起度假的带孩子的母亲，所以先跟孩子套近乎，后来孩子发现男爵另有所图，但他身为孩子并不能理解大人间“灼人的秘密”，所以自己从度假地坐火车去了亲戚家，路上的经历让他和他的母亲重新回归了家庭。
# 月光巷
我在法国海港小巷遇到了奇怪的女店员和男人，原来他们曾是夫妻，因为男人之前的错误女人离家出走沦落烟花柳巷，而男人则一直乞求原谅。
# 国际象棋的秘密
我在船上偶遇国际象棋世界冠军，他之前曾是个傻子，与之比赛中一个陌生人的指点使得冠军不敌，原来陌生人曾被德军拘禁，在紧闭过程中他一直练习棋谱，后练习自己与自己下棋，几乎精神分裂。
# 看不见的收藏
我在通货膨胀货币贬值时想收购一些藏品，便去一个老主顾家，但他已经失明，而且藏品都被家人变卖，我与其家人合演了一出戏安慰老收藏家。
# 日内瓦湖畔的插曲
村民在湖畔救上来一个俄国逃兵，但当他知道不能回家时，他选择了跳河自杀。
# 被遗忘的梦
已婚富有的中年女人在海边别墅偶遇年轻时的旧情人，两人重新燃起旧日情愫，在短暂的暧昧与回忆中重温青春，最终又回到现实。

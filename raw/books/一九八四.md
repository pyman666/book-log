# 简述

温斯顿生活在“老大哥”统治的极权社会，负责篡改历史，却暗中怀疑统治体系；他与朱莉娅秘密相爱并反抗，后来被捕、遭受审讯和思想改造，最终彻底屈服于老大哥。

情节：篡改历史 → 发现党在控制真相 → 与朱莉娅反抗 → 接触“兄弟会” → 被奥布莱恩出卖 → 被捕 → 思想改造 → 最终彻底屈服。

核心思想一句话：**极权统治不仅控制人的行为，还通过监控、宣传、篡改历史和控制语言，最终试图控制人的思想与现实本身。**


# 梗概

故事发生在超级国家大洋国，由神秘的老大哥统治。主人公温斯顿在真理部工作，日常任务就是修改历史记录，让过去永远符合党的当前说法。

大洋国长期与另外两个超级国家——欧亚国、东亚国——交战，而且敌我关系会突然改变；昨天还是盟友，今天就可能宣布一直是敌人。温斯顿因此逐渐意识到，党不仅控制现实，也控制人们对过去的记忆。

温斯顿偷偷反抗党，并与同事朱莉娅恋爱。后来他以为自己接触到了地下反抗组织兄弟会，并得到神秘人物奥布莱恩的帮助。

但实际上奥布莱恩是党的核心成员，温斯顿和朱莉娅被捕。温斯顿在爱情部遭受酷刑和思想改造，最终在101号房间面对自己最大的恐惧，彻底背叛朱莉娅，接受党的思想。

最后：温斯顿不只是被迫服从，而是真心“爱老大哥”——个人的反抗意志被彻底摧毁。

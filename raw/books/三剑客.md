# 梗概

年轻贵族 达达尼昂 离开家乡到巴黎闯荡，想加入国王的火枪队。他先后结识了三个火枪手 阿多斯、波尔多斯、阿拉密斯，四人因为一次决斗成为朋友，并一起卷入法国宫廷斗争。

王后 安娜·奥地利 与英国贵族 白金汉公爵 有秘密感情，黎塞留主教想利用这件事打击王后。王后曾把一串钻石项链送给白金汉，国王却要求王后在舞会上戴上这串项链。达达尼昂和三剑客于是冒险赶往英国取回钻石，最终及时救王后渡过危机。

随后，达达尼昂爱上了王后的侍女 康斯坦丝，同时得罪了黎塞留的女间谍 米莱狄。米莱狄为了报复达达尼昂，制造了一连串阴谋，甚至导致康斯坦丝死亡。

最后，四人追捕米莱狄并将她处决；但三剑客也逐渐走向不同的人生道路。达达尼昂最终成为火枪队长，阿多斯、波尔多斯、阿拉密斯则各自退出江湖。

# 人物简介

| 人物       | 身份        | 作用                     |
| -------- | --------- | ---------------------- |
| **达达尼昂** | 年轻贵族、火枪手  | 主角，冲动勇敢，从乡下青年成长为成熟的军官  |
| **阿多斯**  | 三剑客之一     | 沉稳、有贵族气质，实际上与米莱狄有过去    |
| **波尔多斯** | 三剑客之一     | 爱炫耀、贪图享受，但非常讲义气        |
| **阿拉密斯** | 三剑客之一     | 温文尔雅，想当神职人员，同时又沉迷爱情和权力 |
| **米莱狄**  | 黎塞留的间谍    | 全书最重要的反派，聪明、狠毒、善于伪装    |
| **康斯坦丝** | 王后侍女      | 达达尼昂爱的人，最终被米莱狄害死       |
| **安娜王后** | 法国王后      | 宫廷阴谋的核心人物              |
| **黎塞留**  | 法国首相/红衣主教 | 与王后政治斗争，是达达尼昂等人的主要对手   |

### 各章内容

| 章节               | 内容                                                                      |
| ---------------- | ----------------------------------------------------------------------- |
| **第一章 绝顶的官僚**    | 万历逐渐厌倦朝政，围绕皇位继承问题与群臣长期争执。大臣们要求立长子朱常洛为太子，万历却偏爱郑贵妃所生的朱常洵，双方开始长期拉锯。        |
| **第二章 和稀泥的艺术**   | 万历始终不愿彻底解决“国本”问题，朝臣不断上疏，皇帝则不断拖延、妥协。最终朱常洛被立为太子，但郑贵妃及其支持者仍没有放弃。           |
| **第三章 游戏的开始**    | 围绕太子问题的政治斗争继续升级，随后发生“妖书案”等事件，有人散布攻击皇帝、郑贵妃及其党羽的文字。朝廷开始调查幕后人物，党争进一步扩大。    |
| **第四章 混战**       | 东林党逐渐形成，东林人士与齐党、楚党、浙党等政治集团相互攻击。朝廷中各种人事任免、案件处理都逐渐与党派斗争联系起来。              |
| **第五章 东林崛起**     | 东林党借国本问题不断扩大影响，并逐渐在朝廷中形成较强势力。与此同时，东林与其他官僚集团的冲突越来越激烈，后来又牵连出“梃击案”等重大事件。   |
| **第六章 谋杀**       | 朱常洛即位后不久发生“红丸案”，皇帝服用红丸后突然死亡。围绕红丸是谁提供、是否有人故意谋害皇帝，朝廷展开调查，形成晚明“三大案”中的最后一案。 |
| **第七章 不起眼的敌人**   | 辽东局势开始成为明朝越来越严重的问题。努尔哈赤统一女真各部后建立后金，逐渐与明朝发生大规模战争；明朝开始重新调整辽东防线。           |
| **第八章 萨尔浒**      | 明朝为了消灭后金，调集大军进攻努尔哈赤，并采取分兵合击的战略。努尔哈赤集中兵力逐个击破明军，萨尔浒之战以明军惨败告终，辽东局势彻底恶化。    |
| **第九章 东林党的实力**   | 天启皇帝朱由校即位，东林党在朝廷中的影响进一步扩大。与此同时，魏忠贤逐渐得到皇帝信任，并开始利用宫廷关系和宦官系统建立自己的势力。       |
| **第十章 小人物的奋斗**   | 朱常洛死后，朱由校即位。宫廷中的普通人物也开始因为皇帝继位而改变命运，魏忠贤从不起眼的宦官逐步进入权力中心。                  |
| **第十一章 强大，无比强大** | 魏忠贤与客氏关系密切，又得到天启皇帝信任，开始迅速扩张权力。大量官员依附于魏忠贤，阉党逐渐控制朝廷，并与东林党发生正面冲突。          |
| **第十二章 天才的敌手**   | 辽东战事继续恶化，努尔哈赤不断攻城略地。明朝需要寻找能够对抗后金的将领，孙承宗开始受到重视，并着手重新构筑辽东防线。              |
| **第十三章 一个监狱看守**  | 魏忠贤的势力进一步扩大，开始清除反对者。东林党官员在政治斗争中不断失势，许多官员被罢官、逮捕甚至下狱。                     |
| **第十四章 毁灭之路**    | 魏忠贤逐渐建立起庞大的政治网络，许多官员争相依附于他。与此同时，东林党遭到全面打击，朝廷内部的政治斗争越来越激烈。               |
| **第十五章 道统**      | 东林党与阉党之间的斗争已经从具体政务扩大到政治理念和士人身份之争。魏忠贤要求官员服从自己的权力体系，东林人士则不断进行抵抗。          |
| **第十六章 杨涟**      | 杨涟公开弹劾魏忠贤，列举其大量罪状，成为反对魏忠贤最著名的官员之一。魏忠贤随后发动反击，杨涟被捕入狱。                     |
| **第十七章 殉道**      | 杨涟、左光斗等东林人士遭到严刑审讯，许多人在狱中死亡。与此同时，魏忠贤进一步清洗东林党，制造“六君子”“七君子”等案件。            |
| **第十八章 袁崇焕**     | 袁崇焕登上辽东战场。他提出依靠宁远、锦州等坚城逐步建立防线，并使用红夷大炮抵御后金骑兵。宁远之战中，明军击退努尔哈赤的进攻。          |
| **第十九章 决心**      | 袁崇焕决定继续坚守辽东，并准备以宁远为基础逐步收复失地。后金方面则继续调整战略，双方在辽东进入长期对峙。                    |
| **第二十章 胜利的结局**   | 后金再次进攻宁远，袁崇焕率军坚守并再次击败后金军。努尔哈赤在战斗后伤势恶化并去世，袁崇焕取得宁远大捷；全书以这场阶段性胜利收尾。        |

## 主要人物

### 明朝皇室

| 人物      | 经历                                                      |
| ------- | ------------------------------------------------------- |
| **万历**  | 长期围绕太子人选与群臣争执，后来逐渐怠于朝政。“国本之争”成为他与文官集团长期冲突的重要原因。         |
| **朱常洛** | 万历长子，长期因为郑贵妃和朱常洵而无法顺利成为太子，最终即位成为明光宗，但登基仅一个月左右便因“红丸案”去世。 |
| **朱由校** | 明熹宗，朱常洛之子。对政务兴趣有限，重用魏忠贤，使其掌握巨大权力。                       |
| **郑贵妃** | 万历宠妃，希望自己的儿子朱常洵成为太子，是国本之争中的重要人物。                        |

### 东林党

| 人物      | 经历                           |
| ------- | ---------------------------- |
| **顾宪成** | 东林书院的重要人物，东林政治力量的代表之一。       |
| **杨涟**  | 东林党重要官员，公开弹劾魏忠贤，后来被捕并死于狱中。   |
| **左光斗** | 东林党重要人物，与杨涟一起反对魏忠贤，最终遭到迫害而死。 |

### 魏忠贤集团

| 人物      | 经历                                          |
| ------- | ------------------------------------------- |
| **魏忠贤** | 原本是普通宦官，得到朱由校信任后迅速掌权，联合客氏并拉拢大量官员，形成庞大的政治集团。 |
| **客氏**  | 朱由校的乳母，与魏忠贤关系密切，两人共同影响天启朝政治。                |

### 辽东战场

| 人物       | 经历                                                   |
| -------- | ---------------------------------------------------- |
| **努尔哈赤** | 统一女真、建立后金，并不断进攻明朝。萨尔浒大胜后取得辽东战争主动权，最终在宁远之战后去世。        |
| **李成梁**  | 明朝辽东名将，早期长期镇守辽东，对女真各部采取分化和控制政策，其时代的辽东局势对后金崛起产生了重要影响。 |
| **孙承宗**  | 明朝重要军事人物，负责整顿辽东防务，重视宁远、锦州等防线建设，并培养和支持袁崇焕。            |
| **袁崇焕**  | 从文官转为辽东将领，依靠宁远等坚城和火炮抵御后金，最终在宁远之战中击败努尔哈赤。             |

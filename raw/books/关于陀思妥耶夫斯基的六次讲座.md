
| 讲次      | 核心观点                                                                                           |
| ------- | ---------------------------------------------------------------------------------------------- |
| **第一讲** | **陀思妥耶夫斯基首先是一个矛盾的人。** 他身上同时存在信仰/怀疑、个人主义/自我牺牲、民族主义/欧洲主义等互相冲突的力量，不能简单归结为某一种思想。                   |
| **第二讲** | **理解陀氏必须理解“俄罗斯性”。** 他的思想和人物不是纯粹西方式的理性体系，而深受俄罗斯民族、东正教和社会环境影响；他的“反理性”倾向尤其重要。        |
| **第三讲** | **陀氏真正厉害的是把矛盾变成人物。** 他不替人物解决思想问题，而是让相互冲突的思想同时存在于一个人身上，所以人物总在自我否定、自我反驳。                         |
| **第四讲** | **陀氏特别关注“孩子”和人的原始状态。** 儿童、受苦者、被社会排斥的人，在他那里具有特殊的道德意义；同时，他认为精神性的爱可以凌驾于肉体欲望之上。       |
| **第五讲** | **陀氏人物的核心不是“性格”，而是灵魂的分裂。** 一个陀氏人物往往同时是谦卑的又是骄傲的、想自我牺牲又想证明自己，人物越矛盾，越接近真实的人。                      |
| **第六讲** | **陀氏的文学与他的身体、疾病和精神经验有关。** 纪德特别谈到癫痫，并试图把这种极端生理经验与陀氏作品中的精神强度联系起来；但这一部分现在看带有明显的时代局限。 |

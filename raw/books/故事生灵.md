| 故事         | 两三句简介                                                                                                                |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| **《任氏》**   | 任氏是一个狐妖，偶然与贫穷的郑六相识，两人结为夫妻。她不仅容貌绝世，而且颇有情义，甚至帮郑六的朋友韦崟成全了一段男女关系；后来郑六也逐渐明白，妖怪虽是“异物”，同样有感情和道义。                            |
| **《库麦荣》**  | 山村妇女库麦荣酷爱剪纸，但丈夫嫌她不务正业，把她带到山林里，试图彻底断掉她的兴趣。她在那里遇到一只狼，同时又受到纸店老板王顺山的欣赏和鼓励，最终丈夫反而不再阻止她剪纸，她的剪纸技艺也越来越出色。         |
| **《油月亮》**  | 尤佚人从小遭遇家庭破裂和母亲自杀，性格逐渐扭曲，后来连续杀人。被捕后，他在审讯和法庭上仍显得木讷、单纯，最后交代自己杀人并卖肉给饺子馆的事情，“油月亮”正是人肉饺子里的油花。                |
| **《猎人》**   | 官场得意、好色的戚子绍为了讨好一个女人，带人进山猎熊。夏清不断怂恿他猎熊掌，最终两声枪响把这场猎艳游戏变成了人与熊的悲剧。                                            |
| **《沙地》**   | 故事写一个人在荒凉的沙地上与狮子般的强大力量相遇，人物在危险和困境中逐渐改变自己的处世方式。故事更多通过人与野性的遭遇来推进，而不是传统意义上的完整传奇情节。                                      |
| **《瘪家沟》**  | 写偏僻山沟里一群普通人的生活，他们相信山中有守护土地和生灵的“山灵”。现实生活中的贫困、欲望和人与人的冲突，与这种古老的山野信仰交织在一起。                                               |
| **《龙卷风》**  | 一个山村突然遭遇巨大的龙卷风，房屋、树木、牲畜和坟墓都被卷入灾难之中。人在这种完全无法控制的自然力量面前显得极其渺小，故事基本围绕这场突如其来的灾变展开。                                        |
| **《阿尔萨斯》** | 故事借一个名叫“阿尔萨斯”的古代故事写人在卑微处境中的挣扎：人物不断忍受屈辱，又以近乎自残的方式维持自己的生存。所谓“壁虎”意象，就是断尾求生式的自我保护。                                       |
| **《饺子馆》**  | 饺子馆老板贾德旺没什么文化，却因为熟读字典而纠正了文化人胡子文的读音，两人于是合作把饺子馆包装成“儒商”场所。胡子文想出“认生僻字免费吃饭”的噱头，生意迅速火爆，后来文化、商业和攀附权势逐渐搅在一起。     |
| **《土炕》**   | 围绕一张土炕和一个家庭展开，核心人物是一个把全部精力放在孩子身上的母亲。生活虽然贫困而琐碎，但母亲始终承担着家庭中的照料和牺牲。                                                     |
| **《制造声音》** | “我”去采访一位已经离休的老专员，对方放给“我”听一段录音，让“我”辨认风吹树木的声音。故事由这个声音展开，逐渐牵出官场、人情和一个地方长期积累的是非。                            |
| **《文物》**   | 故事围绕一件古代文物以及与它有关的人展开，现实中的人因为文物而产生不同的欲望和算计。所谓“女夷”的神话意象，与现实中的文物、土地和人的生活相互交织。                                           |
| **《远山野情》** | 有矿的山村里，漂亮少妇香香长期被大队书记霸占，丈夫跛子却靠她换来的钱苟活。后来香香遇到真正把她当人的外乡人吴三大，最终跟他一起离开矿山，寻找新的生活。                              |
| **《天狗》**   | 天狗是师傅李正的徒弟，对师娘有深厚而复杂的感情；师傅受伤成为残废后，他花掉娶妻的钱给师傅治病，甚至放弃自己的婚事。最后师傅自杀，临终仍把妻子和孩子托付给天狗。                           |
| **《黑氏》**   | 黑氏先嫁给嫌弃自己的“小男人”，被抛弃后又嫁给老实的木犊；木犊虽然可靠，却木讷寡言，而来顺一直体贴她，于是她最终与来顺私奔。小说基本就是黑氏在三个男人之间不断选择、被选择，以及她逐渐意识到自己真正想要什么的过程。 |
| **《倒河流》**  | 一个经历大半生起落的人回望自己走过的道路，财富、地位和人与人的关系最终都像河流一样流逝。故事借“龟”这个缓慢背负一生的形象，把一个人的晚年、回忆和对人生得失的回望串起来。                                |

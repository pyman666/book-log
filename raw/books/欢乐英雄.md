# 主要人物

江湖上有一座很奇怪的宅子，住着四个年轻人：

- 郭大路 = 快乐的普通人
- 王动 = 装废物的绝顶高手
- 燕七 = 女扮男装的机灵鬼
- 林太平 = 离家出走的富家公子

组合：

- 郭大路 × 燕七
- 王动 × 红娘子
- 林太平 × 玉玲珑

| 人物      | 性格特点                            | 身世                                         |
| ------- | ------------------------------- | ------------------------------------------ |
| **郭大路** | 乐观、没心没肺、穷 | 出身普通，江湖上没有显赫背景，四人中最像一个“普通人”                |
| **王动**  | 懒、聪明深沉、武功高          | 曾是江湖上赫赫有名的高手，后来厌倦江湖恩怨，隐居在富贵山庄              |
| **燕七**  | 善于谋划，内心细腻      | **真实身份是女子**，父亲是神秘高手**南宫丑**，为了躲避江湖纷争长期女扮男装  |
| **林太平** | 温柔敏感、有担当       | **名门富家子弟**，父亲是“陆上龙王”，因不愿接受家族安排的婚事离家出走 |

# 剧情时间线


1. 郭大路混得一贫如洗

郭大路什么都会一点，却干什么都干不好。实在没钱后，他甚至动了抢劫的念头，于是跑到“富贵山庄”准备打劫。

2. 郭大路认识王动

他发现所谓富贵山庄其实穷得叮当响，主人王动整天躺在床上睡觉。郭大路没抢到钱，反而把自己的剑当掉买酒，和王动喝了起来，两人就这么成了朋友。

3. 燕七逃到富贵山庄

燕七被几个外号“蚂蚁”的高手追杀，逃到富贵山庄。王动出手帮她摆脱追杀，她也因此住了下来。

4. 林太平出现，四人正式聚齐

燕七在路上遇到落难的林太平，把他带回山庄。林太平实际上是“陆上龙王”的儿子，因为不愿接受家里安排的婚姻而逃出来。于是郭大路、王动、燕七、林太平四个人开始共同生活。

5. 四人卷入麦老广和假捕快案件

山下卖烧鸭的麦老广看起来只是普通商贩，实际上是个盗贼。与此同时，一群所谓的捕快来到当地查案，四人调查后发现，真正有问题的恰恰是这些“捕快”——他们利用身份抢夺、侵吞财物。四人最后揭穿了这场黑吃黑的骗局。

6. 一箱箱金银财宝送上门

一个叫“酸梅汤”的女孩带着人来到山庄暂住，临走时留下了大量金银珠宝。四人却发现这些钱来路不明，最后选择放弃财富。随后这批钱又牵出六扇门、盗贼凤栖梧等人物和案件。

7. 王动的过去开始浮出水面

山庄附近出现奇怪的稻草人和暗号，王动看到后反常地紧张。原来他以前并不是现在这个懒散的“废人”，而是江湖上赫赫有名的“一飞冲天鹰中王”，曾经和红娘子等人一起闯荡江湖。

8. 王动与旧日朋友反目

王动后来厌倦了江湖生活，才隐居富贵山庄。但昔日伙伴已经走上歧途，甚至反过来找他麻烦。四人被卷进这场旧日恩怨，王动也不得不重新面对过去。

9. 林太平的身世和婚事暴露

林太平是名门之后，家里给他安排了未婚妻玉玲珑。玉玲珑来到富贵山庄后，两人最初互相看不顺眼，但后来逐渐产生感情。

10. 燕七的秘密被揭开

郭大路一直把燕七当成男人，甚至因为自己越来越在意燕七而怀疑自己是不是“喜欢男人”。实际上王动和林太平早就知道：燕七其实是女人。燕七的父亲是神秘人物南宫丑，而且背负着江湖上的恶名。

11. 四人的友情经受真正考验

王动过去的仇家再次找上门，林太平也遭遇危险。尤其王动的旧日伙伴红娘子等人出现后，四人不得不共同面对敌人。王动甚至为了救林太平，故意利用昔日朋友的贪欲，让他们彼此争斗。最终靠四人的配合渡过危机。

12. 郭大路终于发现燕七是女人

郭大路后来终于撞破燕七的真实身份，也知道南宫丑就是她的父亲。之前那些“同性恋”的误会全部消失，他这才意识到自己其实早就喜欢上了燕七。

13. 燕七离开，郭大路追妻

燕七因为两人的感情问题离开，郭大路这才真正着急。他一路追过去，在经历各种考验之后终于追回燕七，两人最终走到一起。

14. 王动和红娘子重新走到一起

王动与红娘子虽然有过恩怨，但旧情并没有完全消失。经历一系列冲突后，两人最终重新走到了一起。

15. 林太平和玉玲珑成婚

林太平原本逃婚，但经过一系列事情，他终于承认自己爱上玉玲珑，两人的关系也最终确定下来。

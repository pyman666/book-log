# 探讨

> **村上的短篇怎么感觉跟他的长篇一点都不一样？长篇就是苦咖啡，短篇感觉神神叨叨的**

村上的短篇和长篇确实像两个不同的村上。简单说：

长篇 = “现实生活 + 孤独/爱情/失去 + 大量日常细节”

短篇 = “日常生活突然裂一个口子 → 钻进一个莫名其妙的东西”

村上的短篇其实很像“梦”。尤其是《列克星敦的幽灵》这一类： 现实 → 一点异常 → 异常扩大 → 梦一样结束。它不要求你解决“到底发生了什么”。

而且村上短篇有一个特点：他很喜欢“一个点子写到底”。比如《第七位男士》： 小时候被海浪吓到 → 一辈子害怕海 → 最后重新面对海。故事非常简单。但村上会把这个“恐惧”写成一种近乎梦魇的东西。

所以如果把村上的作品粗暴分一下：

长篇村上：孤独的人在现实世界里生活，偶尔碰到一个通往另一个世界的门。

短篇村上：门突然出现在客厅里。

# 梗概

## 列克星敦的幽灵

我在帮美国建筑师看家时遇到幽灵，夜里听见客厅有人说笑，第二天却发现屋里根本没人，留下挥之不去的恐惧。他母亲去逝父亲睡了几星期，父亲去世他睡了几星期

## 绿兽

家庭主妇碰到绿兽求婚；她冷酷地拒绝并把它逼回地下。

## 沉默

大泽自幼练拳击，只揍过一次人

## 冰男

我嫁了冰男，去南极时我好孤独；冰男最终在那里找到了真正适合自己的生活。

## 托尼瀑谷

托尼老爸曾在上海风生水起，后在日本吹爵士。托尼画机械画赚了不少，妻子买了很多衣服，后去世；妻子死后，他面对塞满整间房子的衣服，开始为这些遗物发愁。

## 第七位男士

男人少年时目睹好友被台风巨浪卷走，几十年后仍无法摆脱恐惧，甚至不敢再靠近海水。

## 盲柳，及睡女

少年陪表姐去医院，途中遇到一名失明男子；与此同时，一个女孩长期陷入奇异的昏睡，现实与梦境逐渐混在一起。

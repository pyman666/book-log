# 梗概

自然真美 → 我好感动 → 夏绿蒂真美 → 我好痛苦 → 世界真美 → 我更痛苦 → 我要死了。

# 人物简介

* **维特（Werther）**：年轻艺术家，敏感多情、热爱自然；爱上已订婚的夏绿蒂，明知没有结果仍无法自拔，最终开枪自杀。
* **夏绿蒂（Lotte）**：维特深爱的女子，善良温柔，照顾弟弟妹妹；已与阿尔伯特订婚，后来嫁给他，对维特有感情但始终没有选择他。
* **阿尔伯特（Albert）**：夏绿蒂的未婚夫、后来的丈夫；理性稳重、性格克制，与维特相处时既欣赏他又对他的感情保持警惕。
* **维特的母亲**：维特的母亲，主要通过书信出现；希望维特处理好事务、回到正常生活。
* **威廉（Wilhelm）**：维特的好友，也是维特书信的主要收信人；维特不断向他倾诉自己的爱情、痛苦和绝望。
* **农民青年**：维特在乡间遇到的年轻人，深爱一位寡妇；后来因爱情和占有欲杀死自己的情敌，最终被捕，成为维特悲剧的一个对应案例。
* **伯爵**：维特在社交圈中认识的贵族，邀请维特参加宴会；维特因身份等级问题受到贵族社会排斥。
* **小男孩们**：夏绿蒂照顾的弟弟妹妹；维特非常喜欢他们，常陪他们玩，也是他与夏绿蒂关系中的重要纽带。

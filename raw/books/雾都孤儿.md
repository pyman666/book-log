# 梗概

孤儿奥利弗·退斯特出生在济贫院，母亲产后去世，从小受尽虐待。后来他逃离济贫院来到伦敦，被小偷团伙头目费金收留，被迫学习偷窃。

奥利弗在一次行窃中被好心人布朗罗先生收留，但又被费金一伙抓回。之后他被迫参与一次入室抢劫，受伤后被梅利夫人一家救下。费金和暴徒赛克斯仍想把他重新抓回去，而赛克斯的情人南希则暗中帮助奥利弗。

后来，奥利弗的身世逐渐被揭开：他的父亲是富有的埃德温·利福德，母亲是阿格妮丝·弗莱明，而费金背后还有奥利弗的同父异母哥哥蒙克斯。蒙克斯为了独吞父亲的遗产，故意让费金把奥利弗培养成小偷。

南希将蒙克斯的阴谋告诉布朗罗等人，但被赛克斯发现并杀害。随后蒙克斯的阴谋被揭穿，奥利弗确认了自己的身份并得到父亲留下的遗产。费金最终被判绞刑，赛克斯逃亡时意外摔死，蒙克斯因犯罪入狱，奥利弗则被布朗罗收养，过上了安稳的生活。


# 人物

| 人物            | 与奥利弗的关系 / 情节                                                 |
| ------------- | ------------------------------------------------------------ |
| **奥利弗·退斯特**   | 主角。埃德温·利福德与阿格妮丝的儿子，出生后母亲去世，在济贫院长大，后来被费金拉入小偷团伙，最终身世被揭开并得到遗产。  |
| **布朗罗先生**     | 收留并保护奥利弗的好心人，后来查清他的身世，最终收养他。                                 |
| **阿格妮丝·弗莱明**  | 奥利弗的母亲。与埃德温相爱并怀孕，未婚生下奥利弗后去世。                                 |
| **埃德温·利福德**   | 奥利弗的父亲，富有的绅士。去世后留下遗产，遗产继承问题成为整个阴谋的核心。                        |
| **蒙克斯**       | 奥利弗同父异母的哥哥。为了独吞父亲的遗产，故意让奥利弗陷入犯罪，希望他因此失去继承资格。最终阴谋败露并入狱。       |
| **费金**        | 伦敦小偷团伙头目。收留奥利弗并训练他偷窃，实际上受蒙克斯利用。最终被捕并绞死。                      |
| **比尔·赛克斯**    | 费金手下的暴徒，强迫奥利弗参加抢劫，并杀死南希。逃亡时从屋顶摔死。                            |
| **南希**        | 赛克斯的情人，也是费金团伙成员。虽然身处犯罪团伙，却同情奥利弗，后来冒险向布朗罗等人透露蒙克斯的阴谋，最终被赛克斯杀死。 |
| **梅利夫人**      | 奥利弗参与抢劫时的受害者之一，后来发现奥利弗并非坏人，与家人一起保护他。                         |
| **罗斯·梅利**     | 梅利夫人的侄女，后来揭示她其实是**阿格妮丝的妹妹、奥利弗的姨妈**。                          |
| **班布尔先生**     | 济贫院的管理员，奥利弗童年时期虐待和压迫他的代表人物，后来生活潦倒。                           |
| **机灵鬼杰克·道金斯** | 费金手下的少年小偷，把奥利弗带进费金的团伙。                                       |

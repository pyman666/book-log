# 暴风雪

回程遇上暴风雪，最终抵达驿站。

> 作者从高加索回来，于1854年1月24日在顿河草原上遇到暴风雪，照作者的说法，他“整夜在瞎跑”，当时他就构思了这篇小说，两年后才动笔，1856年2月12日写完于彼得堡，初次发表于1856年第四期《现代人》杂志。小说以高超的手法描写了大自然，深入细致地描绘了受暴风雪摆布的人们的体验。

# 卢塞恩

我在卢塞恩鄙视英国人，并请演唱歌手吃饭。

> 写于1857年托尔斯泰第一次出国旅行期间，初次发表于1857年第9期《现代人》杂志。小说是托尔斯泰根据他在瑞士卢塞恩（琉森）地方亲眼看到的一件事情写成的。作者揭露了西欧资产阶级的自私本性和资本主义同艺术相地对的实质，但这里也出现了否定资本主义文明的相对进步意义的倾向。

# 三死

两个人和一棵树的死亡。

| 对象        | 怎么死                                         | 托尔斯泰想写什么                     |
| --------- | ------------------------------------------- | ---------------------------- |
| **贵妇人**   | 身患重病，害怕死亡，一直想去国外治疗，希望通过医学、祈祷等办法逃避死亡；最终还是死去。 | 人越执着于自己的生命和身份，越无法坦然面对死亡。     |
| **车夫费多尔** | 生病后知道自己快死了，却没有贵妇人那么强烈的恐惧，比较平静地接受命运。         | 普通人反而可能比上流社会的人更接近自然、真实的生命状态。 |
| **树**     | 最后一个农夫为了给贵妇人的坟墓做十字架，把一棵树砍倒；树自然地倒下、死亡。       | 树没有恐惧、挣扎和自我意识，只是顺应自然规律。      |

贵妇人 → 费多尔 → 树，真正有意思的是：三种死亡其实越来越**“自然”**。所以托尔斯泰实际上在做一个很冷酷的对比：

**人越有“自我意识”，越容易害怕死亡；越接近自然，越能够接受死亡。**

所以最后其实是在说：

**个人觉得自己的死亡是天大的事情，但对于自然和整个生命循环来说，一个人的死亡并没有那么特殊。**

# 谢尔盖神父

卡萨茨基因未婚妻曾是沙皇情妇而出家成为谢尔盖神父。为了反自然成圣剁掉自己的手指头，但是却被一个最自然的丑女人引诱了，最后靠童年旧友悟道。

**《谢尔盖神父》不是在说“宗教是假的”，而是在说：一个人越想证明自己高尚、虔诚、纯洁，就越可能把“自我”偷偷塞进信仰里；真正的精神觉醒反而发生在他放弃“成为圣人”之后。**


| 人物       | 简介                                             |
| -------- | ---------------------------------------------- |
| **李寻欢**  | 主角，小李探花，“小李飞刀”例不虚发。重情重义，却因为把林诗音让给义兄龙啸云而背负一生痛苦。 |
| **林诗音**  | 李寻欢青梅竹马、原本的未婚妻，后来嫁给龙啸云。她是整个故事最核心的情感纠葛。         |
| **阿飞**   | 年轻的“飞剑客”，性格孤僻、骄傲，剑法极快。与李寻欢结为知己，后来爱上林仙儿。        |
| **龙啸云**  | 李寻欢的结拜大哥、救命恩人。爱上林诗音后夺走义弟的爱人，后来逐渐走向阴险和疯狂。       |
| **林仙儿**  | “天下第一美人”，极擅长利用男人。表面柔弱美丽，实际上心机深沉，是阿飞最大的情感劫难。    |
| **孙小红**  | 天机老人孙女，聪明活泼，真正理解李寻欢。后来与李寻欢相爱，是小说后期的重要人物。       |
| **上官金虹** | 金钱帮帮主，兵器谱排名第二，野心极大，是李寻欢后期最强大的对手。               |
| **荆无命**  | 上官金虹的第一高手，左手剑客，冷酷寡言，实力极强。                      |
| **天机老人** | 兵器谱第一高手，孙小红的祖父，武功深不可测，也是李寻欢非常敬重的人。             |
| **龙小云**  | 龙啸云与林诗音的儿子，年纪虽小却阴狠毒辣，是龙啸云性格的延续。                |

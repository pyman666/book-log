
| 篇目             | 剧情简介                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| **警察与圣歌**      | 流浪汉索比为了进监狱过冬，故意吃霸王餐、闹事甚至调戏女人，却始终无法如愿。最后他听到教堂圣歌，决定重新做人，却偏偏在此时被警察抓走。         |
| **真朋友蒂勒默克斯**   | 蒂勒默克斯和朋友一起行骗，后来为了朋友的安全主动承担罪责。结果朋友却出卖他，反而显出所谓“真朋友”的荒诞。                      |
| **带家具的房间**     | 一个年轻人到处寻找曾经爱过的女孩，终于在一间出租屋里发现她曾经住过的痕迹，却得知她已经死亡。他无法接受现实，最终在同一间房里自杀。          |
| **托宾的手相**      | 托宾找人算手相，希望从掌纹中知道自己的命运，却发现所谓命运并不能真正解决人的困境。故事借此调侃迷信和人对未来的幻想。                 |
| **圣贤的礼物**      | 穷困夫妻吉姆和德拉分别卖掉自己最珍贵的东西，为对方购买圣诞礼物：德拉卖头发买表链，吉姆卖金表买发梳。两人的礼物最终都暂时失去用途，却证明了彼此的爱。 |
| **二十年后**       | 老朋友鲍勃与吉米约定二十年后在老地方见面，鲍勃如约而来，却不知道吉米已经成为警察。吉米认出他是通缉犯，只好让另一名警察将他逮捕。           |
| **最后一片叶子**     | 生病的琼西认为窗外最后一片常春藤叶落下时自己就会死。老画家贝尔曼冒雨在墙上画下一片永不掉落的叶子，让琼西重新燃起活下去的希望，却因此染病去世。    |
| **为麦克花的钱**     | 一个女人为了寻找失散的男人麦克不断花钱、奔波，后来发现自己对麦克的感情远比想象中复杂。欧·亨利用错位的信息制造最后的反转。              |
| **财神与爱神**      | 富翁安东尼计划用钱买到爱情，但最终发现真正的爱情无法单靠金钱获得。财富、爱情和身份在阴差阳错中发生了反转。                      |
| **失算**         | 一个自认为精明的人设计好了周密计划，却因为一个意外因素功亏一篑。故事主要靠最后的反转表现“聪明人也会算错”。                     |
| **“姑娘”**       | 一个男人爱上一个身份普通、甚至不起眼的姑娘，周围人却认为两人并不般配。最后真正重要的是感情而不是别人眼中的身份和外表。                |
| **没说完的故事**     | 一对男女因为误会和没有说出口的话错过了彼此。等真相揭开时，已经无法重新开始。                                     |
| **五月是个结婚月**    | 一桩婚姻因为双方各自隐藏的过去和误会变得复杂，最后意外揭开真相。欧·亨利用婚姻中的信息差制造幽默效果。                        |
| **艾基·舍恩斯坦的春药** | 艾基为了追求女人，弄来所谓能增强爱情的“春药”。结果药物和感情都出了意外，反而造成一连串滑稽场面。                          |
| **命运之路**       | 大卫·莫尔斯站在岔路口，不同选择会进入完全不同的人生：一条路走向财富，一条走向犯罪，另一条走向死亡。三条人生同时展开，说明命运往往取决于偶然选择。  |
| **口哨大王迪克的圣诞袜** | 一个贫穷、古怪却很有本领的男人通过吹口哨等方式获得机会。故事最后又把他的才能和圣诞节联系起来，形成温情的结局。                    |
| **心理分析与摩天大楼**  | 两个人在摩天大楼里谈论心理和人的行为，原本一本正经的心理分析最终被现实中的荒诞行为打破。作品讽刺把复杂人性简单理论化的做法。             |
| **一笔通知放款**     | 一个男人因为一笔贷款通知陷入经济困境，原本看似普通的商业文件却改变了他的生活。最后通过信息误读和意外揭示真相。                    |
| **圣罗萨里奥的两位朋友** | 两个朋友身处危险环境，却因为误会和身份问题陷入困境。最终他们的友情和忠诚通过一次关键选择得到证明。                          |
| **好汉的妙计**      | 一个看似强悍的人为了达到目的制定计策，却发现真正有效的办法并不靠蛮力。结局用反转把“好汉”的形象重新解释。                      |
| **剪狼毛**        | 一个理发师或商人利用人的虚荣心赚钱，看似普通的小生意里充满欺骗和算计。最后真正被“剪掉”的并不是表面上那样简单。                   |
| **决斗**         | 两个男人因为女人和尊严发生冲突，准备决斗解决问题。真正的矛盾却在最后被一个意外揭开，所谓英雄气概显得可笑。                      |
| **布莱克·比尔藏身记**  | 警察追捕罪犯布莱克·比尔，他为了躲避搜捕不断改变身份。最终藏身的方法与警方的判断形成反转。                              |
| **各有所长的结局**    | 两个人分别凭借自己的特殊才能解决问题，原本互相竞争，最后却发现各自都有无法替代的优势。                                |
| **部长的良策**      | 一位部长面对政治或社会难题，自认为提出了高明办法，却被现实中的一个小问题轻易破坏。故事借此讽刺官僚式的聪明。                     |
| **绿色门**        | 一个男人在纽约街头发现一扇神秘的绿色门，进去后遇到一位年轻女子并爱上她。后来他再次寻找那扇门，却发现它背后隐藏着完全不同的真相。           |
| **经验与狗**       | 一个自认为很懂狗的人凭经验判断一只狗的行为，结果现实完全出乎预料。故事借动物反过来嘲笑人的“经验主义”。                       |
| **几位侦探**       | 几个人各自认为自己很会破案，围绕一桩案件展开调查。最后真正的答案却以最简单、最意外的方式出现。                            |
| **一千元**        | 一个穷困男人突然得到一千美元，原本以为这笔钱能改变人生，却发现钱越多反而带来新的麻烦。最终他找到一种既能保住尊严又能解决问题的办法。         |
| **十月与六月**      | 一个年轻女人和年长男人之间产生感情，年龄差让这段关系看起来不合常理。故事最终说明爱情并不完全按照年龄和社会规则运行。                 |
| **纪念品**        | 一个男人想给心爱的人留下纪念品，却因为身份、金钱或误会陷入困境。最后真正珍贵的东西与他原先计划的完全不同。                      |
| **“真凶”**       | 一桩案件看起来证据确凿，所有人都认定了一个凶手。最后真正的情况被揭开，表面的证据和真实事实发生反转。                         |
| **无缘**         | 两个人明明彼此有感情，却因为身份、时机或误会始终无法走到一起。等到条件终于改变时，两人的人生已经错开。                        |
| **似戏非戏**       | 一对男女在戏剧般的巧合中相遇，现实与表演逐渐混在一起。最后发现原本以为是演戏的事情，恰恰是真实的感情。                        |
| **寻找巧遇的人**     | 一个男人故意寻找某种“偶遇”，希望借此改变自己的生活和爱情。最终真正的巧遇以完全意想不到的方式发生。                         |
| **托尼娅的红玫瑰**    | 一个男人带着红玫瑰寻找托尼娅，背后牵涉旧情和误会。最后玫瑰真正送到的人以及这段感情的真相发生反转。                          |
| **生活的波折**      | 普通人的生活因为一次偶然事件突然改变，人物原来的计划全部被打乱。经过一连串意外后，事情又回到一个出人意料的结果。                   |
| **卖冤仇**        | 两个人因为过去的仇恨准备报复对方，但过程中逐渐发现双方之间存在误会。最后“仇”反而成了促成和解或新关系的契机。                    |
| **多情女的面包**     | 一个女人因为爱情和同情心帮助别人，却因为自己的误解付出了代价。最后真相揭开，显示她的“多情”既可爱又带有讽刺意味。                  |
| **难猜到的母鸡**     | 一个看似普通的家庭或生意问题围绕一只母鸡展开，人物都根据自己的经验做判断。最后事实完全出乎所有人的猜测，形成典型的欧·亨利式结尾。          |

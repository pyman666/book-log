
| 篇名            | 情节简述                                              |
| ------------- | ------------------------------------------------- |
| **押寨夫人**      | 湘西土匪头子抢走一个漂亮姑娘，本想强娶，姑娘发现寨主英俊豪爽，反而主动留下做“押寨夫人”。     |
| **顾问官**       | 一个混迹军队、给人出谋划策的“顾问官”，在湘西军政混乱中周旋，写他的机灵、世故和军队生活。     |
| **会明**        | 一个普通士兵会明，老实木讷，战争中跟随部队行动；枪林弹雨中，他依然保持着普通人的朴素生活愿望。   |
| **逃的前一天**     | 一个即将逃离湘西的年轻人，在离开前一天经历人与事的告别，写出乱世中人物对故乡和生活的复杂感情。   |
| **三个男子和一个女人** | 三个男人围绕一个女人产生感情纠葛，女人的选择和三个男人不同的性格，构成一段带有湘西色彩的爱情故事。 |
| **黄昏**        | 黄昏时分，人物在湘西乡村相遇、交谈和经历一些小事，故事很淡，重点是男女之间微妙的情感变化。     |
| **一只船**       | 围绕一只船和水上人的生活展开，写船夫、渡河者等普通人的生活与情感，带有浓厚的湘西水乡气息。     |

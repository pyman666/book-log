
| 篇名            | 内容简述                                |
| ------------- | ----------------------------------- |
| **常德的船**      | 写常德水运、船夫和码头生活，展现沅水上的日常世界。           |
| **沅陵的人**      | 写沅陵当地各种人物、生活习俗以及不同社会阶层。             |
| **白河流域几个码头**  | 依次介绍白河沿岸几个码头，写当地商业、交通和居民生活。         |
| **泸溪・浦市・箱子岩** | 沿沅水旅行，写三个地方的山水、码头和人物。               |
| **辰溪的煤**      | 写辰溪煤矿，包括矿工、运输以及煤炭带来的地方变化。           |
| **沅水上游几个县分**  | 旅行考察式地介绍沅水上游几个县的地理、物产和民情。           |
| **槐化镇**       | 写一个湘西小镇的街道、居民、商业和日常生活。              |
| **凤凰**        | 写沈从文自己的故乡凤凰，重点描绘当地山水、城市生活和各种人物。     |
| **苗民问题**      | 从湘西苗族的历史、社会处境和民族关系出发，讨论当时所谓的“苗民问题”。 |

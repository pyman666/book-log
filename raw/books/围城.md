# 围城

| 人物      | 简述                                                                       |
| ------- | ------------------------------------------------------------------------ |
| **方鸿渐** | 主角，留学归国的知识分子，聪明但懒散、虚荣、缺乏行动力。先后与苏文纨、唐晓芙、孙柔嘉发生感情纠葛，最终与孙柔嘉结婚，却发现婚姻成了新的“围城”。 |
| **苏文纨** | 方鸿渐留学时认识的女子，漂亮、有教养、家庭条件好，比较矜持且有心机。她喜欢方鸿渐，但更在意自己的体面和掌控感，后来嫁给曹元朗。          |
| **唐晓芙** | 方鸿渐真正喜欢的女人，年轻、漂亮、聪明，性格比苏文纨直接。两人彼此有好感，却因为误会和苏文纨的干涉最终没有在一起。                |
| **孙柔嘉** | 方鸿渐后来结婚的对象，表面温顺，实际上很有主见，也很会算计现实生活。婚后两人的性格冲突越来越严重。                        |
| **赵辛楣** | 方鸿渐的朋友兼情敌，精明、世故、有行动力，曾经追求苏文纨。后来与方鸿渐逐渐成为真正的朋友。                            |
| **李梅亭** | 大学教授，精于算计、爱占便宜，旅途中表现出自私和猥琐的一面，是小说讽刺知识分子的重要人物。                            |
| **顾尔谦** | 大学教授，表面斯文体面，实际上圆滑世故，和李梅亭等人组成知识分子群像。                                      |
| **曹元朗** | 苏文纨的丈夫，诗人，自命风雅，实际上颇为庸俗，是钱钟书讽刺“假风雅”的对象。                                   |
| **高松年** | 三闾大学校长，善于权术和经营人际关系，代表大学里的官僚作风。                                           |


# 写在人生边上

从人生的各种矛盾谈起：人一边活着，一边又不断给人生加上各种解释和意义。

# 人·兽·鬼

四篇

## 上帝的梦

上帝做梦，造男，后造女，男/女分别找上帝再造女/男。后男/女死；

## 猫

- 爱默：李太太，小圈子社交中心；
- 李建侯：爱默夫，后发现有情人；
- 齐颐谷：李先生秘书，暗恋爱默；

## 纪念

- 曼倩：大家闺秀，才叔妻，疑似怀天健子；
- 才叔：曼倩夫，家贫；
- 天健：才叔表弟，飞行员，与曼倩偷情，后空难牺牲；

## 灵感

作家在地府碰到自己笔下人物和生前故交，后投胎成为一个没有灵感的青年作家的儿子。

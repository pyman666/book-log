# 故事梗概

全书基本可以理解成 比利三次进入墨西哥的“穿越”，而且每一次都是带着一个目的进去，最后却得到完全相反的结果。

## 第一次：送狼回故乡

比利一家住在新墨西哥边境的牧场。附近有一只母狼不断袭击牲畜，比利和父亲设法捕获了她。

但比利没有杀她，反而产生了一种近乎执拗的责任感：

这头狼本来属于墨西哥的山野，他要把她送回去。

于是一个16岁的少年，带着一头母狼穿越美墨边境。

然而到了墨西哥以后，他发现那个世界根本不会按照他的道德想象运行。母狼最终被当地人夺走，沦为斗犬/取乐的对象。比利无法救她，只能亲手结束她的生命。

然后他一个人回家。 结果发现——家已经毁了。

## 第二次：和弟弟去找被偷走的马

家园遭到破坏后，比利和弟弟博伊德去墨西哥寻找被盗的马。

这次故事从“人与动物”变成了“兄弟与世界”。

两兄弟一路遇到各种奇怪的人： 这也是《穿越》非常典型的结构：**主线冒险故事走一段，就突然停下来听一个陌生人讲一大段人生故事。**

后来博伊德中枪受伤，两兄弟又与一个年轻女孩产生关系。最终博伊德跟着女孩走了，比利回到了美国。

## 第三次：寻找弟弟

比利后来得知： 博伊德死了。于是他第三次穿越边境。

这一次已经没有什么“冒险目标”了。 他只是想： 找到弟弟，把他的尸体带回家。

他找到博伊德的墓，把尸体挖出来，准备带回美国。

但是途中又遭到暴力和抢夺，博伊德的遗骸甚至被人亵渎。比利最后还是设法把弟弟带回美国重新安葬。

## 内涵

小说最后，比利已经几乎什么都没有了。

有一天，他遇到一条受伤、肮脏、可怜的流浪狗。

这时候其实是在重复小说最开始的“狼”。

年轻时的比利：

看到一头受伤的野狼 → 想救它 → 想把它送回故乡。

现在的比利：

看到一条受伤的狗 → 一开始却把它赶走。

但狗走了以后，他突然产生强烈的悔恨，于是追过去寻找它，最终崩溃痛哭。

这个结尾其实非常狠。

所以《穿越》到底讲什么？

表面上：

一个美国少年三次进入墨西哥的西部冒险故事。

但真正的故事其实是：

一个少年不断试图“把事情做对”，然后一次次发现世界根本不按照人的善意运行。

第一次：

救狼 → 狼还是死了

第二次：

找回家庭财产 → 家庭已经不存在了

第三次：

把弟弟带回家 → 弟弟已经死了

最后：

想帮助一条狗 → 连一条狗都没能留住

所以“The Crossing / 穿越”不只是跨越美国和墨西哥的边境。

它实际上是不断在穿越：

童年 → 成年

希望 → 失望

文明 → 荒野

生 → 死

人与动物

人与人

以及最后：

现实 → 某种无法解释的命运。

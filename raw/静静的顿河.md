[静静的顿河](https://baike.baidu.com/item/《静静的顿河》/2377604)
# 第一卷
格里高力爱上了有夫之妇阿克西妮亚，父亲反对他们的关系，并为格里高力安排了一门亲事，新娘是娜塔莉亚；
# 第二卷
格里高力和阿克西妮亚私奔到了老将军家，阿克西妮亚为格里高力诞下一个女婴，娜塔莉亚自杀未遂；
# 第三卷
格里高力应征入伍，并进入一战战场。因为救了一名军官而受到嘉奖，期间接受到了革命思想。阿克西妮亚因女儿夭折陷入绝望，并与老将军的儿子李斯特尼次基私通。格里高力回乡知情后回到了娜塔莉亚身边；
# 第四卷
沙皇被推翻，临时政府被解散，复辟也偃旗息鼓。军营的哥萨克们接受到革命思想，厌战的哥萨克们陆续从军队陆续回到家乡；
# 第五卷
格里高力加入布尔什维克军队，不久因战功而被提升。他在人民政权和哥萨克应自治之间摇摆。当白军来袭击苏维埃军队时，他受了伤，他不想参与任何党派争斗，只有和平的劳动才让他感到温暖。
# 第六卷
村里组织志愿兵，向赤卫队进攻。格里高力也支持志愿兵的行动，红军开始反攻，不少哥萨克，包括格里高力的岳父被枪决。与红军的战斗中，彼特罗也被杀害。格里高力出于对红军的仇恨加入了暴动军队，并很快升为师长。在之后的撤退中他又与阿克西妮亚重修旧好。
# 第七卷
娜塔莉亚意识到丈夫又和阿克西妮娅在一起了，决心流掉正在怀着的孩子，不幸因失血过多而死去。妲丽亚因染上梅毒，选择了投水自杀。暴动军败局已定，鞑靼村村民选择逃难，逃难途中，潘捷莱不幸去世，格里高力选择加入红军。
# 第八卷
格里高力从军队复员回家，其间母亲已经去世，杜尼亚也嫁给了米沙，但米沙还是决定逮捕格里高力，格里高力在逃跑过程中加入了匪帮。后来他从匪帮逃走，并带上来阿克西妮亚，结果阿克西妮亚不幸中弹身亡。格里高力万念俱灰，回到了家乡，此时女儿也已夭折，只剩下了儿子。
